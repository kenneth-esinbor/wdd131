Website Planning Document

Local Coffee Shop & Café Guide

Kenneth Esinbor

1. Site Name

Proposed Site Name: Local Coffee Shop & Café Guide

Description: This name is professional and instantly communicates to visitors that the site is a curated collection or guide focused on discovering local coffee houses.

Optional domain availability: local-coffee-guide.org

2. Site Purpose

A responsive three-page website dedicated to exploring local coffee shops. It features a Home page with an overview, a Cafes page showcasing a dynamic catalog of local spots powered by JavaScript objects and arrays with filtering capabilities, and a Contact/Review page with an interactive form that saves user feedback using localStorage. A separate unstyled references page will be linked in the footer.

3. Target Audience Scenarios

  • What are the highest-rated local coffee shops near me that offer specialty drinks and great atmospheres?
  • Where can I find the review form to submit feedback or recommend a new local café?

4. Color Schema

The chosen color palette reflects a warm, inviting coffeehouse aesthetic:

Primary: #3D2314 (Dark Roast Brown) - Used for headers, navigation, and primary text.
Secondary: #D2B48C (Tan / Warm Latte) - Used for backgrounds, card borders, and accents.
Accent: #C68B59 (Caramel) - Used for hover states, buttons, and highlights.
Background: #FDFBF7 (Cream White) - Main page background color.

5. Typography

We will use up to two clean, readable web fonts:

  • Heading Font: Merriweather or Georgia (Serif) – Applied to all <h1>, <h2>, and <h3> elements for an elegant, editorial feel.
  • Body Font: Roboto or Arial (Sans-serif) – Applied to paragraphs, navigation, and form elements for clean readability.
